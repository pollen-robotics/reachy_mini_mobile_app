Qwen3-TTS voice preview samples
===============================

These MP3s are short bundled audition clips for the nine Qwen3-TTS
CustomVoice speakers used by the Hugging Face realtime backend.

Source:

- Dataset: https://huggingface.co/datasets/malaiwah/qwen3-tts-customvoice-ab-clips
- Dataset commit: a321ca8e87c4c38bbfa31f324e931127332515c2
- Source files: `original/<speaker>_English.wav`
- Vendored on: 2026-06-03

The source dataset describes these clips as generated with
`CustomVoice.generate_custom_voice(speaker=X)`.

Regenerate or replace these samples if the deployed backend changes model,
speaker ids, voice tuning, or preview text.
